# Uncle Project — Website Portfolio

Website statis responsif Uncle Project dengan logo dan dokumentasi proyek yang diberikan pengguna.

## File
- `index.html` — halaman website
- `assets/logo.png` — logo resmi
- `assets/` — foto proyek House Kudus, Krematorium Hewan, Teras, dan visualisasi desain

## Preview
Buka `index.html` di browser. Koneksi internet diperlukan untuk Google Fonts. Semua foto portofolio disimpan lokal di folder `assets/`.

## Sebelum dipublikasikan
1. Tinjau kembali keterangan proyek agar sesuai dengan lingkup pekerjaan yang benar.
2. Tombol konsultasi menggunakan WhatsApp Click to Chat ke +62 812-2231-712 dengan pesan awal otomatis.
3. Periksa izin penggunaan foto, logo, dan materi brand.
4. Domain `uncleproject.com` harus didaftarkan jika belum dimiliki dan tersedia.

## Publikasi via GitHub Pages
1. Buat repository publik baru di GitHub dan unggah seluruh isi folder ini (termasuk `assets/`).
2. Buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`.
3. Jika domain tersedia dan sudah dimiliki, tambahkan custom domain `uncleproject.com` pada pengaturan Pages.
4. Atur DNS registrar mengikuti panduan resmi GitHub: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
5. Aktifkan HTTPS setelah konfigurasi DNS terdeteksi.
